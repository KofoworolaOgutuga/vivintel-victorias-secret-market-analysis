# Data

## Overview

This folder contains data-related files used in the Victoria's Secret market analysis.

The project uses consumer research data from **Vividata** to analyze lingerie purchasers and compare Victoria's Secret consumers with other relevant consumer groups.

## Data Source

The primary research source is:

**Vividata**

The Victoria's Secret consumer segment was identified through the Vividata category:

> Apparel → Shopping → Miscellaneous Products → Women's Clothing → Where Personally Bought/Past 12 Months (National)

## Data Used

The analysis focuses on variables related to:

* Victoria's Secret purchasing
* Other lingerie retailers
* Consumer demographics
* Shopping behaviour
* Consumer attitudes
* Personal characteristics
* #MeToo-related attitudes

## Data Privacy & Licensing

Vividata data may be subject to licensing, copyright, and access restrictions.

For this reason, this repository should **not include raw proprietary Vividata data unless redistribution is explicitly permitted**.

Where necessary, files in this folder should contain only:

* Student-created analysis
* Non-proprietary summaries
* Derived tables
* Screenshots or visuals permitted for portfolio use
* Documentation describing the methodology

## Data Preparation

The general preparation process involved:

1. Identifying the relevant Vividata category.
2. Selecting Victoria's Secret purchasers.
3. Identifying appropriate comparison groups.
4. Selecting demographic variables.
5. Selecting behavioural variables.
6. Selecting relevant attitude questions.
7. Creating cross-tabulations for comparison.

## Important Note

The results presented in this project should be interpreted as findings from the available Vividata research data rather than as a representation of all Victoria's Secret customers.
